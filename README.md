# VACON — AI 기반 팀 휴가 및 업무 연속성 관리 비서

팀원의 휴가 일정과 업무 정보를 분석해 **업무 공백을 사전에 예측(Prediction)**하고,
**대체 담당자를 추천(Recommendation)**하며, **인수인계 문서를 자동 생성(Automation)**하는 Streamlit 앱입니다.
외부 API 키·유료 서비스 없이 규칙 기반으로 모든 핵심 기능이 동작합니다.

## 설치 및 실행

Python 3.10+ 필요.

```bash
cd vacon
python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 http://localhost:8501 이 열립니다. 첫 실행 시 `data/vacon.db`(SQLite)가 만들어지고
가상 샘플 데이터(팀원 9명·업무 13개·휴가 8건)가 자동 입력됩니다. 샘플 날짜는 **실행 시점의 이번 주 월요일 기준**이라
언제 실행해도 시연이 가능합니다.

| 환경변수 | 설명 |
|---|---|
| `VACON_DB` | DB 파일 경로 변경(기본 `data/vacon.db`) |
| `VACON_TODAY` | 오늘 날짜 고정(YYYY-MM-DD). 시연·재현용 |
| `ANTHROPIC_API_KEY` | (선택) 설정 + `pip install anthropic` 시 AI 비서가 규칙 기반 결과를 자연어로 요약 |
| `VACON_LLM_MODEL` | (선택) LLM 모델명 변경 |

## 주요 기능

| 화면 | 내용 |
|---|---|
| 📊 대시보드 | 오늘 부재 인원, 이번 주 휴가, 위험 건수, 대체자 미지정 업무, 날짜별 가용 인원 차트, 고위험 업무와 대응 방안 |
| 🗓️ 휴가 캘린더 | 주간/월간 부재 히트맵, 날짜별 부재 인원, 중복 휴가 구간, 휴가 등록·수정·삭제(입력 검증 포함) |
| ⚠️ 위험 분석 | 업무별·날짜별 Low/Medium/High, 점수 기여 근거와 권장 대응. 계산 불가 시 '데이터 부족' |
| 🤝 대체 담당자 | 후보 점수·추천 이유·예상 업무 부담·주의사항, 제외 사유 표시. **'지정' 버튼을 눌러야만 반영** |
| 📝 인수인계 | 휴가 선택 → 문서 미리보기/편집 → Markdown·TXT 다운로드. 데이터 없는 항목은 '미입력' |
| 📧 메일 요약 | 휴가 기간에 받은 메일(.eml/CSV/붙여넣기/샘플)을 기간별로 걸러 우선순위·회신 필요·관련 업무·기한 기준으로 요약하고 복귀 브리핑(Markdown)으로 저장 |
| 💬 AI 비서 | 규칙 기반 자연어 질의(아래 지원 질문 참고) |
| 🗂️ 데이터 관리 | 팀원(MBTI 포함)·역량·업무·마감일 CRUD, 위험 규칙 설정, 샘플 초기화 |

### 위험도 판단 방식 (`services/risk.py`, `services/config.py`)
담당자가 부재인 날을 기준으로 가중치를 합산합니다(데이터 관리 > 위험 규칙에서 변경 가능).

`담당자 부재 30 + 중요도(상 20/중 10) + 대체자 미지정 25 또는 대체자도 부재 25 + 마감 임박(3일 이내) 20 + 역량 보유 근무자 없음 20 + 팀 가용 인원 50% 미만 10`
→ 점수 ≥ 75 **High**, ≥ 40 **Medium**, 그 외 **Low**.
담당자·중요도가 비어 있으면 안전하다고 단정하지 않고 **데이터 부족**으로 표시합니다. 위험도는 **근무일(월~금)** 기준입니다.

### AI 비서 지원 질문
- "다음 주에 업무 공백 위험이 높은 날짜는?"
- "휴가 중인 핵심 담당자가 누구야?" (핵심 담당자 = 중요도 '상'인 미완료 업무의 담당자)
- "대체 담당자가 지정되지 않은 업무를 알려줘."
- "이번 주 휴가 인수인계 문서를 만들어줘."
- 그 외: "오늘 부재 인원은?", "이번 주 위험도가 높은 업무 목록"

기간 표현은 오늘/내일/이번 주/다음 주/이번 달/다음 달을 인식합니다. 지원하지 않는 질문은 추측하지 않고 안내합니다.

### 메일 요약 (`services/mail_digest.py`)
메일 서버에는 연결하지 않으며 사용자가 가져온 메일만 처리합니다(저장하지 않고 세션 메모리에만 유지).
- 입력: `.eml` 여러 개 / CSV(`받은날짜,보낸사람,제목,본문`) / `보낸사람: · 받은날짜: · 제목:` 형식 붙여넣기 / 샘플 메일
- 처리: 선택한 기간 안의 메일만 요약(기간 밖·날짜 없는 메일은 따로 표시) → 긴급/요청/공지 키워드, 본문 내 기한 날짜, 업무명 매칭(2개 이상 일치 시 '추정')으로 우선순위 판단
- 모든 항목에 판단 근거를 표시하며, 규칙 기반 요약이므로 중요한 메일은 원문 확인이 필요합니다.
- (선택) `ANTHROPIC_API_KEY` 설정 시 "AI로 브리핑 다듬기" 체크박스가 나타나며, 체크한 경우에만 메일 제목·요약이 외부 API로 전송됩니다.

## 구조

```
app.py            진입점(좌측 사이드바 세로 메뉴)
views/            페이지별 UI (Streamlit은 `pages/` 폴더를 자동 멀티페이지로 인식하므로 `views/` 사용)
services/         risk, recommend, handover, assistant, calendar, summary, validation, llm
data/             db.py(SQLite 접근), sample_data.py
tests/            서비스·DB 계층 테스트
```

## 제한 사항
- 공휴일·회사 휴무일은 반영하지 않고 주말만 제외합니다.
- 반차는 기본적으로 '부재'로 보지 않고 가용 인원에서 0.5명으로만 계산합니다(규칙에서 변경 가능).
- 업무량·예상 업무 부담은 사용자가 입력한 값을 그대로 사용하며 실제 업무 시스템과 연동하지 않습니다.
- 사용자 인증/권한, 다중 사용자 동시 편집은 지원하지 않습니다(로컬 SQLite 단일 사용자 기준).
- 메일은 자동 수집하지 않습니다(Outlook/Gmail 연동 없음). 메일 요약은 키워드 기반이라 뉘앙스·문맥을 놓칠 수 있습니다.
- MBTI는 팀원 정보로 저장·표시만 하며 위험도 계산이나 대체 담당자 추천에는 사용하지 않습니다.
- 기존 `vacon.db`는 실행 시 `mbti` 컬럼이 자동 추가되어 데이터가 유지됩니다.
- LLM 요약은 선택 기능이며, 규칙 기반 답변을 문장으로 다듬는 용도로만 사용합니다.
